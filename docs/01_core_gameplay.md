# 核心玩法设计

## 游戏循环
```
开始 → 随机地图 → 3-2-1倒计时 → GO → 跑酷中遇到单词挑战点
→ 弹出拼写面板 → 10秒内输入 → 判定结果 → 获得/使用道具
→ 继续跑酷 → 90秒结束 → 结算排名
```

## 单词挑战机制

### 触发规则
- 固定间隔：每跑30%赛道触发一次
- 所有人同时触发，题目从服务器随机下发
- 答题时角色自动减速至30%

### 题型A：补全模式（fill_blank）
```
服务器下发：
  word: "beautiful"
  display: "b_a_t_f_l"  (随机挖空，>5字母挖3+个)
  blank_positions: [1,3,5,7]  // 挖空索引

学生输入：eauu（按顺序补全缺失字母）
```

### 题型B：中译英模式（cn_to_en）
```
服务器下发：
  meaning: "苹果"
  word: "apple"
  length: 5

学生输入：apple（完整单词，无提示）
```

### 判定规则
- 正确：当前速度 × 120% 持续3秒
- 错误：当前速度 × 50% 持续3秒
- 超时：视为错误，强制弹出下一题
- 连续正确计数：用于道具获取

## 道具系统

### 获取条件
- 连续正确答题3题 → 随机获得1个道具
- 道具栏上限2个，满时新道具需选择丢弃

### 道具列表

| 道具 | 类型 | 效果 | 持续时间 |
|------|------|------|---------|
| 火箭 | 增益 | 自身速度 × 250% | 5秒 |
| 电击 | 控制 | 目标麻痹，需连续正确2题恢复 | 至恢复 |
| 香蕉皮 | 控制 | 目标速度 × 15%，正确1题恢复 | 至恢复 |
| 护盾 | 防御 | 抵消一次控制 | 8秒或触发 |
| 磁铁 | 增益 | 自动吸收前方金币（预留） | 6秒 |

### 使用方式
- 点击道具栏图标释放
- 控制类道具：点击后选择目标跑道（1-8）
- 增益类道具：立即对自身生效

## 惩罚与恢复

| 状态 | 触发 | 恢复方式 |
|------|------|---------|
| 减速 | 答错/超时 | 3秒自动恢复 |
| 麻痹（电击） | 被电击命中 | 强制弹出2题，连续正确后恢复 |
| 滑倒（香蕉皮） | 踩香蕉皮 | 强制弹出1题，正确后恢复 |
| 道具栏清空 | 连续答错3题 | 无，重新积累 |

## 追赶机制（Catch-up）

触发条件：距第一名 > 30%赛道
效果：
- 答题时间 +3秒（13秒）
- 答对后加速效果 × 1.5
- 道具获取门槛降为连续正确2题
- 单词难度自动降低1级

## 课堂控制（老师端）

| 功能 | 说明 |
|------|------|
| 即时换词库 | 比赛中切换单词难度/主题 |
| 强制道具雨 | 全员立即获得随机道具 |
| 慢镜头回放 | 3秒慢放精彩瞬间 |
| 一键静音 | 控制全班音效 |
| 暂停/继续 | 全局游戏暂停 |

## 断线重连

```
断线 → 角色AI托管（基础速度，不参与道具）
     → 30秒内重连 → 恢复控制，继承进度
     → >30秒 → 标记"掉线"，变灰半透明继续跑
```

## 单局时长控制

- 严格90秒，服务器端计时
- 不因答题卡顿延长
- 最后10秒：心跳音效 + 画面震动 + 背景音乐加速
