# 客户端设计

## 学生端

### 屏幕适配
- 优先竖屏：跑道横向压缩，键盘在下方
- 横屏模式：键盘浮层覆盖底部30%区域
- 跑道显示区域：顶部40%，始终可见角色

### 竖屏布局
```
┌─────────────────┐
│  [迷你跑道]      │  ← 顶部25%，显示自己角色+前后2人
│  ▓▓▓▓░░░░░░    │
│  距第1名: 12米   │
├─────────────────┤
│  中文：苹果      │  ← 题目区20%
│  输入：______    │
│  剩余: 8秒      │
├─────────────────┤
│  [Q][W][E][R][T]│  ← 虚拟键盘55%
│  [A][S][D][F][G]│    按键72px，间距12px
│  [Z][X][C][V][B]│    无符号键，纯英文
│  [←][空格][提交] │
├─────────────────┤
│  [道具1][道具2]  │  ← 底部10%
└─────────────────┘
```

### 横屏键盘浮层
- 答题时：屏幕中央弹出半透明面板
- 背景：角色慢动作继续跑（速度×0.3）
- 键盘：右侧50%区域，左侧仍显示跑道

### 虚拟键盘规范
- 按键大小：72×72px（手指友好）
- 按键圆角：8px
- 按下反馈：缩放0.95 + 颜色变深
- 布局：QWERTY标准，无数字/符号切换
- 提交键：绿色，醒目

### 跑道视觉规范
- 跑道高度：每条占屏幕高度 10%
- 角色大小：跑道高度的 60%
- 领先者：边框金色发光，角色放大1.2x
- 被控制者：角色灰色 + 闪电/滑倒图标
- 进度条：跑道右侧，绿色填充

### 特效显示
- 电击：释放者到目标的金色闪电连线
- 香蕉皮：目标角色打滑旋转动画
- 火箭：角色尾部火焰拖尾
- 护盾：蓝色半透明球体包裹角色

## 状态机

```
[登录] → [输入姓名] → [输入房间码] → [等待大厅]
                                      ↓
[游戏结束] ← [跑酷中] ← [3-2-1倒计时] ← [准备就绪]
     ↓
[结算页] → [再来一局/退出]
```

## 断线提示
- 网络波动：顶部黄色条 "网络不稳定..."
- 已断线：红色遮罩 "已断开，尝试重连 (3)..."
- 重连成功：绿色提示 "已恢复"
